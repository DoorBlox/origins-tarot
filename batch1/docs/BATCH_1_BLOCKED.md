# GENUINELY BLOCKED

**Client-visible skin, model and nameplate replacement** cannot be faithfully implemented with a server-only Origins datapack + KubeJS scripts. Rev2 Full Faceless Disguise and Borrowed Face need an additional Fabric client rendering/network extension supporting signed skin/profile changes with multiplayer consent. Both have playable invisibility/identity-hint approximations in Batch1.

**Release dependency, not technical impossibility:** Paper Martyr Resonance is reserved for Batch2 (Hanged Man + Resonance Seq9-0). Batch1 prevents the Seq2→1 transition until this kit exists; it does not grant an empty or fake Resonance set.

Other uncertain mechanics have code or explicit partial approximations documented in BATCH_1_APPROXIMATIONS.md.
